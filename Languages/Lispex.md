# Lispex

- **Description** - Lispex is a Lisp-family language for application decision rules. Its Rust implementation provides a source tree interpreter and a virtual machine that validates bytecode before execution. Separate embeddable evaluators accept explicit work and memory limits.
- **Creator** - STUDIO HAZE
- **Release Date** - The first public release date is not established by the official sources linked below; the current release date and repository creation date are not substitutes for it.
- **Links** - [Official Website](https://www.lispex.com/), [Version History](https://www.lispex.com/v1.21/en/docs/history), [Downloads](https://www.lispex.com/v1.21/en/downloads), [Runtime Reference](https://www.lispex.com/v1.21/en/docs/reference/runtime-backends)
- **Applications**
  - Application decision rules
  - Embedded evaluation with explicit resource limits
  - Scheme exercises through the separate SICP profile
