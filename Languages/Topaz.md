# Topaz

- **Description** - Topaz is a general-purpose programming language with typesetting built in. Code that does the same job looks the same no matter who writes it. Its compiler is written in Topaz and emits Rust. This is the language developed by STUDIO HAZE, distinct from the unrelated Topaz language by m-schm.
- **Creator** - STUDIO HAZE
- **Release Date** - The first public release date is not established by the official sources linked below; the current release date and repository creation date are not substitutes for it.
- **Links** - [Official Website](https://topaz.ooo/), [Compiler Release Source](https://github.com/studiohaze/topaz), [Version History](https://topaz.ooo/v5.21/en/docs/project/history), [Installation](https://topaz.ooo/v5.21/en/docs/install)
- **Applications**
  - Typesetting and document software
  - General software development
  - Native programs and browser applications
