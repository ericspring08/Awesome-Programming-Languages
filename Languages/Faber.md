# Faber

- **Description** - Faber (Faber Romanus) is a statically typed language for coding agents and human authors. It has a clear mechanical grammar, explicit static and generic types, and math-oriented operators. The same program renders in eight reader languages, and it compiles to Rust, TypeScript, Go, Swift and more. Faber is experimental through version 1.x.
- **Creator** - Ian Zepp
- **Release Date** - 2026
- **Links** - [Official Website](https://faberlang.dev), [GitHub Repository](https://github.com/faberlang/faber), [Releases](https://github.com/faberlang/releases/releases)
- **Applications**
  - Code written by coding agents and reviewed by people
  - Libraries compiled into existing Rust, TypeScript, Go or Swift projects
  - Programs read in a non-English reader language (Latin, Thai, Chinese and others)
