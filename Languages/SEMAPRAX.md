# SEMAPRAX

- **Description** - SEMAPRAX is an experimental, agent-native systems programming language built around a stable semantic program graph. Human-readable `.spx` source is its canonical Git projection, while deterministic graph and patch formats provide bounded interfaces for program analysis and change. It is pre-alpha research software rather than a production-ready language.
- **Creator** - Wavect GmbH
- **Release Date** - August 7, 2026
- **Links** - [Official Website](https://wavect.io/semaprax/), [GitHub](https://github.com/wavect/semaprax), [Language RFC](https://github.com/wavect/semaprax/blob/main/docs/RFC-0001.md), [Completion Matrix](https://github.com/wavect/semaprax/blob/main/docs/COMPLETION-MATRIX.md), [PLDB](https://pldb.pub/concepts/semaprax.html)
- **Applications**
  - Research into semantic interfaces for coding agents
  - Deterministic program graphs, impact analysis, and evidence-bound changes
  - Experimental systems programming with explicit contracts and ownership checks
  - Bounded native C11/Clang and WebAssembly Core compilation
